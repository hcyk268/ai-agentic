# Hệ Thống AI Agent Đặt Vé Máy Bay 
---

## Hướng dẫn cài đặt & Thực thi

### 1. Cài đặt môi trường
```bash
pip install -r requirements.txt
```

### 2. Tạo env
```bash
cp .env.example .env
```
Điền đầy đủ thông tin llm model sử dụng vào .env

### 3. Chạy Demo 
```bash
python run_demo.py
```

### 4. Chạy Benchmark 
```bash
python run_benchmark.py
```
